## Button

<ArgTypes of={Aura.Button} />

### Button as a link

Give Button an `href` and it renders an `<a>` that looks the same — use it for navigation, keep actions as buttons. Its props are the anchor's (`target`, `rel`, `download`…) plus these; the ref is the `<a>`. For client-side navigation pass your router's link: `<Button href="/orders" linkComponent={Link}>` (`next/link`).

| Prop | Type | Description |
|---|---|---|
| `href` * | `string` | Where it goes. |
| `variant` | `'primary' \| 'secondary' \| 'creative' \| 'danger' \| 'danger-secondary'` | Default `primary`. |
| `icon`, `iconRight` | `IconName \| ReactElement` | `external-link` with `target="_blank"`, or your own icon element. |
| `disabled` | `boolean` | No href, `aria-disabled`, out of the Tab order. |
| `linkComponent` | `React.ElementType` | Router link rendered instead of `<a>`; gets `href`, `className`, children and the ref. Defaults to AuraProvider's `linkComponent`. |

### Destructive actions

`variant="danger"` (red fill) is for the one confirming action in a delete dialog; `variant="danger-secondary"` (red outline) for a destructive action that sits beside others on a page. `IconButton tone="danger"` for a row's delete. Keep the confirm dialog — colour alone doesn't make an action safe.

### Your own icons

Every `icon` prop (and `Icon name`) also takes an element, e.g. `<Button icon={<Building />}>` with lucide-react. AURA sizes it to the same box, strokes it at 2 in `currentColor` and hides it from screen readers.
