# Pickers — props

Values are ISO strings (`2026-09-18`, `09:30`); display is Thai with Buddhist-era years by default. Use react-hook-form `Controller` for these. Tables are generated from the TypeScript sources of `@jirawatpyk/aura-react`, so they always match the published types. `*` = required.

## Combobox

<ArgTypes of={Aura.Combobox} />

With `multiple`, `value` / `defaultValue` are `string[]` and `onChange` gets the whole list; picks show as removable chips, the list stays open between picks, Backspace in the empty field removes the last one, `max` caps the count (further options are disabled), and `name` posts one hidden input per value.
