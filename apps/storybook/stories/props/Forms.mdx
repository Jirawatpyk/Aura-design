# Forms — props

Every field has a visible label, a hint or error line and the 44px height. Fields forward `ref` to the real input (react-hook-form `register`). Tables are generated from the TypeScript sources of `@jirawatpyk/aura-react`, so they always match the published types. `*` = required.

## PasswordField

A TextField with a show/hide button (one name, "Show password", with `aria-pressed`). All TextField props; the ref is the input, so `register` works. `autoComplete` defaults to `current-password` — use `new-password` on sign-up and change-password forms.
