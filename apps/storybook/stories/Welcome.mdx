## Install

```bash
npm i @jirawatpyk/aura-react @jirawatpyk/aura-tokens   # React 18 or newer
```

```tsx
import '@jirawatpyk/aura-tokens/aura.css';      // tokens, light + dark
import '@jirawatpyk/aura-react/styles.css';     // component styles
import { AuraProvider, Button, DatePicker } from '@jirawatpyk/aura-react';

export default function App() {
  return (
    <AuraProvider locale="th">
      <Button icon="plus">New order</Button>
      <DatePicker label="Delivery date" />
    </AuraProvider>
  );
}
```

Fonts come from Google Fonts: add the `<link>` tags from `aura-fonts.css` to your `<head>`, or import that file.

## Try it without a build

Load the files from jsDelivr after React 18 and use `window.Aura`:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@jirawatpyk/aura-tokens@4/aura.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@jirawatpyk/aura-react@4/dist/styles.css">
<script src="https://cdn.jsdelivr.net/npm/react@18/umd/react.production.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/react-dom@18/umd/react-dom.production.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@jirawatpyk/aura-react@4/dist/aura.bundle.js"></script>
```

## Your brand

```bash
npx aura-theme --brand "#0ea5e9" --out src/aura-theme.css
```

Builds a colour scale from one brand colour, maps it onto the brand tokens (links, focus ring, selection, progress) and adjusts anything that misses WCAG AA. Success, warning and danger never change.
